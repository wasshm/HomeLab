Conteneurs — SRV-DOCKER

Un serveur Debian unique, Docker installé via le script officiel, qui porte toute la couche applicative du lab : ITSM, supervision, exposition web.

SRV-DOCKER actif

RôleHôte de conteneurs applicatifs
SystèmeDebian 13
MoteurDocker

Services hébergés

GLPI (prochainement)Gestion de parc / ITSM — inventaire et tickets du lab
Zabbix (prochainement)Supervision infrastructure — disponibilité et métriques des VM
Grafana (prochainement)Visualisation des métriques collectées (dont Zabbix)
PortainerAdministration visuelle des conteneurs Docker
Nginx Proxy Manager (prochainement)Reverse proxy — point d'entrée unique pour les services web
Uptime Kuma (prochainement)Supervision de disponibilité légère, page de statut du lab

Pourquoi cette approche

  • Regrouper les services applicatifs sur une VM légère plutôt que de multiplier les machines virtuelles, pour rester proche des pratiques actuelles de déploiement.
  • Nginx Proxy Manager en frontal permet de n'exposer qu'un point d'entrée HTTPS maîtrisé vers OPNsense, plutôt qu'un port par service.
  • Zabbix + Grafana donnent une vraie chaîne de supervision (collecte → visualisation), réutilisable telle quelle sur un poste en entreprise.
